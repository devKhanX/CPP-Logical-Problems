Question: Maximum Consecutive Wins
A game consists of N rounds. In each round, a player either wins (W) or loses (L).
Determine:
1. The longest consecutive winning streak.
2. How many times that maximum streak occurred.
Example:

Input:
10
W W L W W W L W W L
Output:
Longest streak: 3
Occurred: 1 time
Constraints:
- Do not use strings.
- Read one character at a time.
- Solve in a single traversal.
